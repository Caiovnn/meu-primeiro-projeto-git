1. Por que o commit é importante?
O commit é importante porque registra as alterações feitas em um projeto, criando um histórico das mudanças ao longo do tempo.

Imagine que você está desenvolvendo um site. Primeiro, cria a página inicial; depois, adiciona um formulário e, por fim, altera o visual. Cada commit pode registrar uma dessas etapas.

2. Qual é a vantagem do GitHub?
O GitHub permite armazenar projetos online, compartilhar código e colaborar com outras pessoas. Ele utiliza o Git para controlar as versões dos arquivos.
